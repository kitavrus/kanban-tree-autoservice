# Фаза 2 — авторизация и сотрудники: отчёт

**Итог:** вход/выход, сессии, CSRF, роли и экран «Сотрудники» работают на стенде. Ревью — **APPROVED** (после одного цикла исправлений).

## Что сделано

Вход по логину и паролю (страница `/login` и JSON API), выход, Redis-сессии со скользящим сроком 12 ч и потолком 7 дней (D35). Защита: cookie `sid` HttpOnly + SameSite=Strict (+ `Secure` по настройке), CSRF double-submit без хранилища на всех изменяющих запросах (D40), ограничение неудачных входов по логину — 10 за 15 мин → 429 (D41), одинаковый ответ на «нет логина» / «неверный пароль», сообщение о блокировке — только при верном пароле, защита от open redirect после входа. Роли admin / executor: исполнитель не видит и не открывает «Сотрудников» (страница «Нет доступа», API 403); права читаются из БД на каждом запросе — смена роли и блокировка действуют сразу (D42). Экран «Сотрудники»: список с поиском и фильтрами в URL, создание и правка (ФИО, логин, роль, телефон, пароль, активность), ошибки под полями; удаления нет (D39). D29: нельзя заблокировать себя и лишить систему последнего активного администратора — в том числе при одновременной правке двумя админами. Блокировка убивает все сессии сотрудника, смена пароля — все, кроме текущей своей.
