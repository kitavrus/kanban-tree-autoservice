## Решения пользователя (2026-10-15)

- Срок заказа на доске = «Начать с» + дни − 1 (метка 📅 и фильтр «Горит/просрочено» по
  плановому окончанию); вручную срок больше не вводится.
- Плановые дни прошли, машина не выдана — занимает место до выдачи (как сейчас).
- «Начать с» и «Дней на работу» правятся в карточке существующего заказа.
- Существующие заказы: «Начать с» = дата приёмки (создания), дни = до прежнего срока, без
  срока — 1.
