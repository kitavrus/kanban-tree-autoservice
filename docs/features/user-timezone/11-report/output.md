# Отчёт: user-timezone — часовой пояс пользователя

Часть 2 из 6 мастер-спеки `transfers`. Ветка `feat/user-timezone` (поверх `feat/suppliers`), base `beb6d60`, не запушена.

## Что сделано

У пользователя появился часовой пояс (`users.timezone`, миграция `0013`, умолчание `Asia/Almaty` для новых и существующих). Пояс меняет сам пользователь — выбор в боковой панели, `PUT /api/v1/users/me/timezone` — и администратор любому сотруднику в форме «Администрирование → Сотрудники». Время хранится в UTC и показывается по поясу пользователя на всех экранах и в печатных формах: JS-экраны (доска, карточка заказа, «Выплаты», «Перемещения») и SSR-шаблоны (история оборудования, печать приёма и выдачи). «Сегодня» для фильтров срока и счётчика просроченных услуг — тоже по поясу пользователя, в списке, карточке и ответах мутаций.

## Ревью

**APPROVED** — high 0 / medium 1 / low 8 (`8-code-review/output.md`). Ревьюер независимо прошёл весь JS, шаблоны и Go-код: мест показа времени мимо пояса пользователя не осталось.
