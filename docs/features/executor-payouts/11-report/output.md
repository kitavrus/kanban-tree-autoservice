**Вердикт ревью: APPROVED** (high 0 / medium 0 / low 4) · ветка `feat/executor-payouts` · не запушено, PR не открыт.

## Что сделано

У каждой услуги заказа появился статус выплаты исполнителю: отметка «Выплачено исполнителю», дата отметки и сумма выплаты (отдельная от цены для клиента). Менять их могут и администратор, и исполнитель. Отметка ставится в строке услуги в карточке заказа либо массово на новом экране «Работа → Выплаты» (исполнитель → его услуги → итоги «к выплате / выплачено»). На доске — фильтр «Выплата исполнителю: все / выплачено / не выплачено» и метка «к выплате: N» на карточке заказа, если есть выполненные, но не выплаченные услуги. Решения — D62–D71 в `docs/plan.md`.

Правила:
- отметить выплату можно только у услуги с назначенным исполнителем (иначе 400);
- сменить или снять исполнителя у выплаченной услуги нельзя (409 `SUBTASK_EXECUTOR_PAID`) — сначала снять отметку;
- сумма выплаты правится независимо от отметки; правка других полей услуги выплату не затрагивает;
- исполнитель в отчёте по умолчанию видит свои услуги, фильтр снимается;
- массовая отметка атомарна, не более 500 услуг за раз.

Код: миграция `0011_executor_payouts`, правки `internal/features/board` (услуги, фильтр, метка), новый пакет `internal/features/executorpayouts` (API `GET /api/v1/executor-payouts`, `/summary`, `POST /mark` + SSR-экран), JS карточки/доски/отчёта, seed-demo.
