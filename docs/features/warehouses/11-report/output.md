**Вердикт ревью:** APPROVED (high 0, medium 3 → закрыты, low 5 → 2 закрыты, 3 приняты). Ветка `feat/warehouses` (base 1a7281f), не запушена.

## Что сделано

Добавлены склады (справочник, сид «Алматы», «Москва»; всё существующее мигрировано на «Алматы»). Остаток, минимум, коробка и место товара ведутся по каждому складу (`product_stock`); «Остатки» показывают колонки складов, «Итого» и «В пути», фильтр по складу. Товары заказа списываются со склада строки (по умолчанию — склад оборудования услуги). Перемещения товаров между складами: «Заявка» → «В пути» → «Принято» (приёмка по факту, недостача → `transfer_loss`) / «Отменено». Оборудование заказа принимается на склад, отправляется между складами со статусом «в пути» (откуда → куда), принимается; история перемещений в карточке; фильтр доски по складу и бейдж «в пути». seed-demo раскладывает данные по обоим складам. Миграции 0008–0010, решения D45–D60 в `docs/plan.md`.
