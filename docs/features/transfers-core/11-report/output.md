## Что сделано

`stock_transfers` переименованы в `transfers` (таблицы, пакет `internal/features/transfers`, адреса `/transfers` и `/api/v1/transfers`, экран; миграция `0014`). Документ склад ↔ склад возит и товары, и единицы оборудования клиентов. Местоположение переехало с строки заказа на саму единицу (`equipment.location_status`, `warehouse_id`, `active_transfer_id`); таблица `task_equipment_movements` удалена. Из карточки заказа сняты кнопки «Отправить / Принять / Отменить отправку» — остались бейдж местоположения и ссылка на документ. Добавлен `GET /api/v1/equipment`. Доска, история оборудования и склад по умолчанию строки товара работают от нового источника. Запреты: единица в незавершённом документе не убирается из заказа (в том числе сменой клиента заказа) и не удаляется; склад не архивируется, пока на нём числится оборудование или есть незавершённые документы. Данные мигрируются по DS-054, seed-demo пересоздан под новую модель.
