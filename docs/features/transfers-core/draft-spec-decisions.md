# Draft-spec decisions: Перемещения — ядро (transfers-core)

> Часть 3 из 6 мастер-спеки `transfers`. Вопросы пользователю по этой части отдельно не задавались:
> решения приняты в интервью мастера — `docs/features/transfers/draft-spec-decisions.md`.
> Номера DS и TS — мастер-идентификаторы; новое решение нарезки получило следующий номер (DS-057).

## Откуда решения
- DS-001, DS-003 — мастер-журнал, батч 0. DS-005, DS-008 — батч 1. DS-009, DS-010 — батч 2.
- DS-019 — батч 4. DS-026 — батч 5. DS-027…DS-030 — батч 6. DS-037, DS-054 — батч 7.
- DS-036, DS-041, DS-046, DS-052, DS-055 — inferred мастера; DS-048, DS-049 — as-is (D50–D52); DS-051 — zap.

## Решения нарезки (2026-10-07)
- **DS-057 (inferred, новое):** поиск единиц для кнопки «+ Оборудование» — новый `GET /api/v1/equipment`. В мастере у этого UI-действия endpoint'а не было (пробел мастера); списка единиц по всем клиентам в проекте нет.
- **DS-045 перенесён из этой части в `transfers-partners`** (отступление от плана нарезки): выбор «Склад приёма» при добавлении единицы в заказ остаётся до появления документа «клиент → склад» — иначе между частями 3 и 4 оборудование нельзя было бы принять на склад вообще. Склад при этом пишется на единицу, а не на строку заказа.
- **Колонка `direction` в этой части не вводится** (отступление от плана): пока направление одно, она не нужна; появится в `transfers-partners` вместе с контрагентами.
- Хвосты TS-006, TS-027, TS-036, относящиеся к направлениям с клиентом и к снятию «Склада приёма», помечены в §11 как реализуемые в `transfers-partners`.
