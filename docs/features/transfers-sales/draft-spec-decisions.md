> Часть 5 из 6 мастер-спеки `transfers`. Вопросы пользователю по этой части отдельно не задавались:
> решения приняты в интервью мастера — `docs/features/transfers/draft-spec-decisions.md`.
> Номера DS и TS — мастер-идентификаторы.

## Откуда решения
- DS-011 — мастер-журнал, батч 2, В-7. DS-014 — батч 3, В-9.
- DS-038, DS-039 — inferred мастера.

## Решения нарезки (2026-10-07)
- Товарная строка в документе «склад → клиент» появляется только в этой части, сразу с ценой (в части 4 клиенту уходит только оборудование).
- Значение `client_out` в CHECK причин движений добавлено частью 4 (владелец DS-040); здесь оно начинает писаться.
- Детали, выведенные при написании (без отдельного DS): цена копируется в строку в момент сохранения и позже не пересчитывается при правке каталога; при `PUT` без `price` у товарной строки подставляется цена каталога (строки заменяются целиком); правило «товары, списанные услугами заказа, в накладную не вносят» система не проверяет; строка «Продано по накладным» показывается только при сумме больше нуля; движения накладной не заполняют `stock_movements.task_id` — связь с заказом идёт через документ.
- Строка 26 §Impact мастера (`executorpayouts/dto.go`) проверена поиском: `total_amount` в `internal/` есть только в пакете `board` — шум скана.
