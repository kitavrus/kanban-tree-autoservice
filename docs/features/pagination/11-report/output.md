## Что сделано

Доска больше не обрезает заказы молча. Первичная загрузка — один запрос
`GET /api/v1/tasks?…&per_column=50`: в каждой колонке первые 50 карточек, внизу колонки
«показаны N из M» и «Показать ещё» (догрузка `column_id=&limit=50&offset=N`). В тулбаре —
«Заказов: M», а если на доске видна только часть — «· показаны N». Если первичная выдача
упёрлась в общий `limit=1000`, у колонок без карточек появляется «Показать заказы».
Колонки, исполнители и категории фильтра загружаются всеми страницами. API изменился
только аддитивно: опциональные `column_id` и `per_column`, поле карточки `column_total`,
конверт `{items,total,limit,offset}` прежний (§API-1, `api-delta.md`). Список товаров и
услуг в каталоге теперь постраничный: 100 на страницу, параметр `offset`, пейджер
«Показаны 101–200 из M», фильтры сохраняются. У категорий при превышении лимита
появляется пометка «показаны N из M». Комбобокс товара в форме услуги ищет на сервере.
