=== AC-002: пустая company_name ===
POST /api/v1/clients {"company_name":"",...,"phones":[{"phone":"123","note":""}]}
-> {"code":"VALIDATION","message":"validation failed","details":{"fields":[{"name":"company_name","message":"required"}]}} status=400
=> AC-002 «Без названия компании клиент не сохраняется, сообщение у проблемного поля» — подтверждено.

=== AC-002: телефоны — пустая строка ===
POST /api/v1/clients {"company_name":"Тест",...,"phones":[{"phone":"","note":""}]}
-> {"code":"VALIDATION",...,"fields":[{"name":"phones","message":"required"}]} status=400
=> AC-002 «Без хотя бы одного телефона клиент не сохраняется» — подтверждено (пустая строка нормализуется в 0 телефонов -> required).
