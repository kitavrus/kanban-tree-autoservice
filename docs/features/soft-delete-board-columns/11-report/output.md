# Отчёт: soft-delete-board-columns (часть 3 из 6 мастера soft-delete)

**Дата:** 2026-10-08 · **Ветка:** `feat/soft-delete-board-columns` (стопкой на `feat/soft-delete-transfers`, база `7ab0503`) · **Коммиты:** `9db8395`, `cc88d8c` · **Вердикт ревью:** APPROVED

## Что сделано

Колонка доски удаляется с возможностью восстановления: администратор удаляет пустую колонку с обязательной причиной, она уходит во вкладку «Колонки» раздела «Удалённые» и возвращается кнопкой «Восстановить» в конец доски с прежними признаками «финальная» и «списывает товар». Удалённые заказы больше не удерживают колонку от удаления. Если колонку заказа удалили, пока заказ лежал в удалённых, при восстановлении он встаёт в первую нефинальную действующую колонку с предупреждением, а товар списывается по правилу новой колонки. Перенос заказа в удалённую колонку — «Колонка не найдена».

Технически: миграция `0020_soft_delete_board_columns` (три колонки в `columns`), `DELETE /api/v1/columns/:id` с телом `{reason}` → 200 `{id, deleted_at}` (было 204), `POST /api/v1/columns/:id/restore`, источник вида `columns` в пакете `softdelete`, служебная уборка вида `columns`, перенумерация позиций только по действующим колонкам, удалённая колонка в демо-данных.
