== XSS ==
$ POST /api/v1/subtasks/{sub1}/logs {"text":"<script>alert(1)</script> тест"}
-> 201, JSON возвращает raw text (корректно, экранирование — только на этапе HTML-рендера)
$ PUT /api/v1/tasks/1862/equipment/{EQ1} {"completeness":"<img src=x onerror=alert(1)>"}
-> 201, JSON raw
$ GET /tasks/1862/print/intake, /tasks/1862/print/handover (HTML)
-> оба содержат экранированное `&lt;img src=x onerror=alert(1)&gt;` (grep -n "onerror" подтверждает
   единственное вхождение — в escaped-виде, НЕ raw `<img`). XSS не воспроизведён.
