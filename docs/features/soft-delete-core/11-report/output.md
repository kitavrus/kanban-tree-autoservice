# Отчёт: soft-delete-core (часть 1 из 6 мастера soft-delete)

**Дата:** 2026-10-08 · **Ветка:** `feat/soft-delete-core` (от main `022d8d6`) · **Коммиты:** `5529da1`, `0199660`, `c3195c3` · **Вердикт ревью:** APPROVED

## Что сделано

Удаление заказа стало восстановимым. Администратор удаляет заказ с обязательной причиной — заказ исчезает с доски, из поиска, «Выплат», истории оборудования и итогов, его товары возвращаются на склад. В новом разделе «Удалённые» (вкладка «Заказы») видно, что удалено, кем, когда и почему; кнопка «Восстановить» возвращает заказ со всеми частями и снова списывает товары, а при нехватке товара или заменённой колонке показывает предупреждение. Файлы вложений удалённого заказа с диска не стираются. Для автотестов добавлена служебная физическая уборка, доступная только на стенде с `TEST_PURGE_ENABLED=true`.

Технически: миграция `0018_soft_delete_core` (три колонки в `tasks`), новый пакет `internal/features/softdelete` (общий механизм и реестр видов для частей 2–6, `GET /api/v1/deleted`, `/deleted/summary`, страница `/deleted`), `POST /api/v1/tasks/:id/restore`, условие «заказ не удалён» во всех читателях и путях записи частей заказа.
