## Что сделано

Экран «Каталог» с вкладками «Услуги» / «Товары» / «Типы оборудования» (последняя — экран фазы 3, получил ту же полосу вкладок), `/catalog` ведёт на услуги. Слева — категории текущего вида со счётчиками: создать, переименовать, отправить в архив и вернуть, удалить неиспользуемую; дубль названия без учёта регистра и пробелов по краям запрещён (D16), используемая категория не удаляется — только архив (D26). **Товары:** категория, название, артикул, единица, цена, остаток (дробный, может уйти в минус — «долг»), минимальный остаток (у минимума строка выделена), коробка и место хранения; ручная правка остатка пишется в журнал движений `stock_movements` с дельтой и автором (D44). Товар из комплекта услуги удалить нельзя — только архив. **Услуги:** категория, название, цена работы (пусто — «по факту»), комплект товаров с количеством (дубли объединяются, архивные товары новыми не добавляются, но уже стоящие в комплекте сохраняются — по прецеденту фазы 3). Исполнитель читает каталог через API (для форм заказов фазы 5), изменения — только администратор. Код написан вручную по эталону фаз 2–3 (D43, пересматривает D30), журнал движений заведён уже сейчас (D44) — решения пользователя.
