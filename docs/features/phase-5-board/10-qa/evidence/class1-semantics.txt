## AC-010 — version conflict, данные не затёрты
$ curl -s -X PUT .../tasks/674 -d '{"title":"qa-task-1-edited",...,"version":1}'   # текущая version=2
{"code":"TASK_VERSION_CONFLICT","message":"Заказ уже изменён, обновите"}
HTTP:409
$ curl -s .../tasks/674   # заголовок не поменялся
{"id":674,...,"title":"qa-task-1",...,"version":2,...}
Результат: OK, AC-010 выполняется, поле title не затёрто.
