## Стек операций на своём товаре (qa-product-phase5, id=11111111-...-103, стартовый stock=10)
1. move в consumes-колонку (demand=2) -> stock 10->8; task_stock(674)=2; stock_movements +(-2, task_consume)
2. toggle consumes_stock false -> stock 8->10 (возврат); stock_movements +(+2, task_return)
3. toggle consumes_stock true  -> stock 10->8 (повторное списание); stock_movements +(-2, task_consume)
4. DELETE task 674 -> Reconcile(target=false) -> stock 8->10; stock_movements +(+2, task_return)

$ SELECT (SELECT stock FROM products WHERE id='...103') = 10 + COALESCE((SELECT sum(qty_delta) FROM stock_movements WHERE product_id='...103'),0);
 t
Результат: инвариант «остаток = стартовый(10) + Σ stock_movements.qty_delta» держится после каждого шага (4 движения: -2,+2,-2,+2, итог stock=10). PRD §3 требование выполнено.
