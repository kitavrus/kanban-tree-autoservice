- **E2E оставляет архивных поставщиков в dev-БД** (удаления у сущности нет).
- На экране нет листания: при списке больше 50 записей остальные доступны только поиском (спека не требует).
- Отступления as-built от §6: код ошибки `invalid_text`, `q` длиннее 200 → 400, `limit` вне 1–500 зажимается, `is_active` в query — строго `true|false`.
